# Planet-3d_Web_Model-

**Planeta 3D**: un planeta inventado y cómico en Three.js, por secciones, que se entrega como
un solo HTML que abre sin internet. Portada para GitHub; el contenido vive en otros archivos.

- **Personas:** empieza por `LEEME.md` y, para trabajar a la par, `docs/sistema/COLABORAR.md`.
- **Claude Code:** entra por `CLAUDE.md`. **Cualquier otra IA:** por `AGENTS.md`.
- **El HTML listo:** en *Releases* (D-16), o `npm install && npm run build` → `dist/index.html`.
