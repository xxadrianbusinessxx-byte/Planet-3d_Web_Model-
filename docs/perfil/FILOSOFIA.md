# FILOSOFÍA del perfil — principios propios del tipo de proyecto

PERFIL · base. Sin principios propios todavía: los del núcleo (`docs/normativo/FILOSOFIA.md`)
ya cubren la forma de trabajo.

Cuando el proyecto descubra un principio que solo vale para su tipo, se agrega aquí como
sección `## §P1. Título`, con su porqué y una línea `**Invariante:**`, y se corre
`python scripts/gen_invariantes.py`.
