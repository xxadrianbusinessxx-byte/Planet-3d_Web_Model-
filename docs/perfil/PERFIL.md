# Perfil: base · versión 1.0

**Para:** cualquier proyecto que todavía no encaja en un perfil. Junto con el núcleo es la
plantilla «sin nada»: la forma de trabajo completa, sin suponer qué se construye.

**Variantes:** ninguna.

**Qué aporta:** casi nada, a propósito. Sus documentos son moldes vacíos que el arranque
llena con la persona: dónde va el código, cómo se prueba, qué principios propios hay.

**Qué pasa después:** si el proyecto sale bien, lo que se llenó aquí es la semilla de un
perfil nuevo. El arranque deja registrada esa lección (`"tipo": "plantilla"`,
`"division": "perfil"`) para que la plantilla la recoja.
